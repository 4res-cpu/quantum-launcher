# quantum-datos

Datos que lee el Quantum Launcher al abrirse. Sube esta carpeta como un repositorio público de GitHub
llamado `quantum-datos`.

- `manifest.json`: versión actual del modpack (y del launcher, para avisar a la versión portable).
  Actualízalo con `tools/publicar-modpack.js` del repositorio del launcher.
- `noticias.json`: noticias que salen en el launcher. Se puede editar desde la web de GitHub.
- Los `.mrpack` van en *Releases* de este repositorio (etiqueta `modpack-X.Y.Z`).

Instrucciones completas: `docs/GUIA-ORGANIZADOR.md` en el repositorio del launcher.
